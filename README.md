# Customer Service Sentiment Analysis

## Project Overview
This project analyzes customer service interactions to predict customer satisfaction levels. Using a dataset of service logs, I cleaned the data, performed feature engineering, and compared machine learning models to identify key drivers of satisfaction.

## Key Features
* **Data Cleaning:** Handled missing values and date inconsistencies.
* **Analysis:** Correlation heatmaps and feature importance charts.
* **Modeling:** Compared Logistic Regression vs. Random Forest Classifiers.
* **Results:** The Random Forest model achieved X% accuracy, identifying 'Call Duration' as the top factor in customer churn.

## Technologies Used
* Python (Pandas, NumPy)
* Scikit-Learn (Machine Learning)
* Matplotlib & Seaborn (Data Visualization)
